# Tableau-Pollution-Dashboard
An interactive Tableau dashboard analyzing global air pollution trends, emissions, and environmental indicators to uncover patterns across countries and years.
> Built with Tableau Public using public environmental datasets.

## Project Overview

Air pollution is one of the leading environmental risks affecting public health worldwide. Governments and organizations require clear insights into pollution trends to support policy decisions and resource allocation.

This project transforms raw environmental data into an interactive Tableau dashboard that enables users to:
- Explore pollution levels across countries
- Identify long-term emission trends
- Compare environmental indicators
- Detect geographic hotspots
- Monitor changes over time
The dashboard focuses on turning complex environmental datasets into intuitive visual analytics for decision makers.

## Objectives

The dashboard was designed to answer questions such as:

- Which countries experience the highest pollution levels?
- How have emissions changed over time?
- Which pollutants contribute the most?
- Are there regional patterns?
- Which countries have improved or worsened?

## Dashboard Features

The dashboard includes:

- Interactive filters for country, year, and pollutant
- Geographic map visualization
- Time-series trend analysis
- Country comparison
- KPI summary cards
- Dynamic tooltips
- Drill-down exploration
